# 计算机软件著作权登记 通用办理指南

> 这是一份通用流程说明，不含任何具体项目的填写内容。具体项目的填写稿请只保存在本地，不要提交到代码仓库。各项规则以中国版权保护中心官网当前公布的要求为准。

## 一、办理流程
1. **注册账号**：在中国版权保护中心「著作权登记系统」注册并实名认证（个人用身份证，单位用营业执照）。
2. **在线填写申请表**：选择「计算机软件著作权登记申请」，按页面提示逐项填写。
3. **准备并上传材料**：源程序、软件说明书（用户手册或设计说明书）、身份证明文件，其他材料视情况提供。
4. **提交并打印签章页**：按系统要求签字或盖章后上传（或按指引邮寄）。
5. **等待受理与审查**：受理后进入审查。需要补正时会通知，按要求在期限内补正。
6. **领取证书**：审查通过后可下载电子证书。

## 二、需要准备的材料
| 材料 | 说明 |
|---|---|
| 申请表 | 在线填写，提交后生成，签章页需签字或盖章 |
| 源程序鉴别材料 | 一般为前 30 页 + 后 30 页，共 60 页；不足 60 页的提交全部 |
| 文档鉴别材料 | 软件说明书 / 用户手册，同样前 30 页 + 后 30 页，不足 60 页的提交全部 |
| 身份证明 | 个人：身份证复印件；单位：营业执照副本复印件 |
| 权属证明（如有） | 合作开发协议、委托开发合同、受让合同等 |

## 三、格式要求
### 源程序
- 每页不少于 50 行（结束页除外），去掉空行后连续排列。
- 首页从程序开头开始，末页到程序结尾。
- 每页页眉写软件名称和版本号，并标页码。
- 源码里的版权声明、作者信息要和申请表上的著作权人一致。
- 不要出现与本软件无关的第三方代码大段堆砌；注释保持正常即可。

### 软件说明书
- 每页不少于 30 行（结束页、整页插图页除外）。
- 页眉同样写软件名称和版本号，并标页码。
- 内容一般包括：软件简介、运行环境、功能说明、操作步骤，并配主要界面截图。
- 截图要是本软件的真实界面，图中显示的名称和版本要与申请一致。

### 申请表常见字段
- 软件全称、简称、版本号
- 软件分类、开发方式（独立 / 合作 / 委托 / 下达任务）
- 开发完成日期、发表状态、首次发表日期和地点
- 开发与运行的硬件环境、操作系统、开发工具、运行平台、支撑软件
- 编程语言、源程序量
- 开发目的、面向领域、主要功能、技术特点（注意页面上的字数上限）
- 著作权人信息、权利取得方式、权利范围

## 四、常见补正和驳回原因
1. **名称或版本不一致**：申请表、源程序页眉、说明书页眉、软件界面四处的名称和版本号不完全相同。
2. **源程序页数或行数不对**：不足 60 页却没有提交全部，或每页不到 50 行。
3. **说明书太简单**：只有几张截图，缺少运行环境和功能、操作说明。
4. **截图与申请不符**：截图里显示的名称、版本和申请表不一致，或截图明显不是本软件。
5. **著作权人不一致**：源码或文档中的版权信息与申请人不同，或留着占位符没有替换。
6. **日期矛盾**：开发完成日期晚于首次发表日期，或晚于提交日期。
7. **权属不清**：合作或委托开发却没有提供协议。
8. **功能描述与软件不符**：描述了软件里没有的功能。
9. **分类或技术特点填写随意**：与软件实际情况明显不符。

## 五、建议
- 定版后再生成材料，生成后不要再改界面上的名称和版本号。
- 页眉统一用软件全称或统一用简称，前后保持一致。
- 提交前把材料从头到尾翻一遍，重点核对名称、版本、著作权人、日期四项。
- 填写稿、身份信息、证件扫描件只保存在本地，不要上传到公开仓库。
